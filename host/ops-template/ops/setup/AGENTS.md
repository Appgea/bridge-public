# <your portfolio>

The folder that holds your apps. Start a CLI anywhere. Deny rules and the vault guard are global.

## The brain is `ops/`

Code is the source of truth. `ops/` never restates what a repo proves.
Branch, dirt, versions and store state are read live.

- `now.md` the agenda, cap 40 lines. `backlog.md` the queue, `rg` it, never read whole.
- `company.md` cross-app facts. `portfolio.yaml` the spine. `apps/<key>.md` per-app facts.
- `decisions/index.md` standing choices. `rollouts/<id>.md` one change across apps.
- `runbooks/*.sh` procedures. `para.md` where new things get filed.
- `log/` is the bin. Never read it unless asked.
