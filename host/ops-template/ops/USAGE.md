# Using the system — daily driver

## Launch anywhere
Deny rules and the vault guard are global. `ops/` reaches every CLI through the `ops` skill.

## The loop
1. Work normally in the project. Features, fixes, refactors: do them and commit there. Do not touch the brain.
2. Something durable happened, a decision, a direction change, a new credential: tell the manager in Panel. It files it. `para.md` is the rule.
3. A repeating surgery, Play setup, release, screenshots: run the runbook or the `release` skill.
4. Status or what's next: ask the manager. It reads `now.md` and the current sprint.
5. In `ops/`: commit regularly. That is how it persists.

## What lives where
Read `setup/AGENTS.md`. It is the map, and it is what every CLI reads at the root.
